# ChatVox

## Live Chat TTS Reader for Twitch

ChatVox reads authorized Twitch chat aloud with local Kokoro text-to-speech on
Windows x64.

## Features

- 28 local American and British English voices.
- Twitch EventSub chat reading with saved authorization restoration.
- Words-only speech: emoji and Twitch emotes are removed before TTS.
- Editable ignored users, command/URL filtering, bounded fresh queue.
- System tray, Start with Windows, and start-minimized support.
- Optional startup update checks with Stable and Preview channels.

## Download and install

Download ChatVox from [GitHub Releases](https://github.com/Drakcain/ChatVox/releases).
Run the current installer, launch ChatVox, connect Twitch once, then choose
your preferred voice and settings. Normal upgrades preserve your authorization
and settings.

## Voice support

ChatVox supports American English and British English only. It includes no
eSpeak/eSpeak NG runtime and no multilingual Kokoro voice assets.
