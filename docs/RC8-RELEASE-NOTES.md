# ChatVox 1.0.0-rc.8

## Fixed

- Startup could hide even with **Start minimized to tray** disabled.

## Improved

- Startup now uses an explicit launch context.
- Post-install and post-update launches are always visible.
- Windows startup uses an explicit invocation argument.

## Validation purpose

- First full updater proof from a release containing the corrected updater: RC.7 → RC.8.

## Preserved

- True single-instance behavior and responsive UI.
- Ignore Emoji, username speech, latest-release updates, and Twitch auto restore.
- LocalAppData voice cache, 28 English voices, and eSpeak-free runtime.
