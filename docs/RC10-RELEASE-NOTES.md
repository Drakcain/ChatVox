# ChatVox 1.0.0-rc.10

## Scope

RC.10 improves the optional Username Pronunciation Overrides panel.

- Override text and the section header remain readable in dark mode.
- The panel now explains when it should be used, the required format, and an
  example: `blkdragon76_ttv = black dragon`.
- Leaving the field blank keeps the automatic username pronunciation behavior.

No Twitch, queue, Kokoro, or username-normalization behavior changed in this
release candidate.
